# jSMTLIB

jSMTLIB is an open source implementation of [SMT-LIB](https://smt-lib.org) in Java: a command-line tool,
an API, a language server and an Eclipse plugin, with adapters to many SMT solvers.

- Website, user guide, tutorial and API documentation: <https://smtlib.github.io/jSMTLIB/>
- Releases: [GitHub Releases](https://github.com/smtlib/jSMTLIB/releases) (`jSMTLIB.jar`)

## Getting involved

- Bugs, feature requests and questions: [GitHub Issues](https://github.com/smtlib/jSMTLIB/issues)
- Contributing code: [CONTRIBUTING.md](CONTRIBUTING.md)
- Reporting a vulnerability: [SECURITY.md](SECURITY.md)
