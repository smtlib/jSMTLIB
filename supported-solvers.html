Supported SMT solvers

There are a variety of SMT solvers. In fact there is an annual competition (SMT-COMP) to evaluate the capabilities and performance of publicly available solvers. The jSMTLIB tool works with the solvers contained in the SMTLIB/Solvers GitHub repository. The supported solvers are listed here by platform (as of this writing). There are more solvers than listed here or supported by this tool. Note that solvers have varying capabilities, from specific to certain logics to very general.

smtinterpol is a Java archive and so runs on every platform. The Windows builds are supplied as .exe files.
